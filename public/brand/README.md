## `yanyuan-avatar-pixel.png`

- 用途：AI 策展人“彦远”的对话头像
- 生成日期：2026-08-12
- 生成方式：Codex 内置 `imagegen`，随后以 96×96 像素为母版、最近邻放大至 384×384 PNG
- 身份边界：这是“彦远”AI persona 的虚构视觉身份，不是张彦远的历史肖像，也不声称复原其真实容貌
- 视觉提示词摘要：16-bit PC RPG 像素肖像；唐代文人气质；墨黑、黛青、宣纸与极少朱砂；无文字、印章、Logo 或水印
